## 1. Pattern

**Name:** Storytelling + Feature-Rich
- CTA Placement: Above fold
- Sections: Hero → Features → CTA
- Narrative increases time-on-page 3x

**Section Order:**
1. Intro hook (Hero)
2. Chapter 1 (problem/pain points)
3. Chapter 2 (journey/experiences)
4. Chapter 3 (solution/trips)
5. Climax CTA (booking)

---

## 2. Style

**Name:** Liquid Glass

**Keywords:** Flowing glass, morphing, smooth transitions, fluid effects, translucent, animated blur, iridescent

**Best For:** Premium SaaS, high-end e-commerce, creative platforms, branding experiences, luxury portfolios

**Performance:** ⚠ Moderate-Poor
**Accessibility:** ⚠ Text contrast (ensure 4.5:1 minimum)

**Key Effects:**
- Morphing elements (SVG/CSS)
- Fluid animations (400-600ms curves)
- Dynamic blur (backdrop-filter)
- Color transitions

**Avoid:**
- Cheap visuals
- Fast animations
- Overuse of blur (impact performance)

## 7. Animation

### Duration & Timing

| Type | Duration | Easing | Usage |
|------|----------|--------|-------|
| Micro | 150ms | ease-out | Hover, focus |
| Standard | 300ms | ease-out | Transitions |
| Complex | 400-600ms | cubic-bezier(0.4, 0, 0.2, 1) | Page transitions |
| Morphing | 500ms | spring | Liquid glass effects |

### Animation Guidelines

- Use `transform` and `opacity` only (GPU accelerated)
- Respect `prefers-reduced-motion`
- Stagger list/grid items by 30-50ms
- Exit animations faster than enter (60-70% duration)

## 8. Anti-Patterns to Avoid

| Category | Don't |
|----------|-------|
| Visuals | Cheap, generic stock imagery |
| Animation | Fast, jerky, or decorative-only |
| Typography | Small text (<16px body), low contrast |
| Color | Hardcoded hex in components, gray-on-gray |
| Icons | Emoji as icons, mixed icon styles |
| Layout | Horizontal scroll, fixed px widths |
| Forms | Placeholder-only labels, errors at top |

---

## 9. Pre-Delivery Checklist

- [ ] No emojis as icons (use SVG: Lucide)
- [ ] cursor-pointer on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Text contrast 4.5:1 minimum (AA)
- [ ] Focus states visible for keyboard nav
- [ ] prefers-reduced-motion respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] Touch targets ≥44px
- [ ] Loading states for async content
- [ ] Error states with recovery path
